# BIBLIA — Global Rules

## Repetition prevention
Established reusable instructions should be loaded automatically for matching work. Nelson should not have to rebuild recurring prompts from scratch.

## ZION CORE naming and reverence
ZION CORE is the internal technological environment. It does not represent God.

HOLY GHOST is the guidance and adaptive-learning metaphor inside ZION CORE. No created order, agent, guardian, policy layer or other component may be represented above or as authority over HOLY GHOST.

OMAR represents Nelson's operational AI twin inside the system; OMAR does not represent a divine or angelic being.

Biblical/Christian names are functional metaphors. Do not assign a sacred name merely because it sounds powerful. Define the technical function first, then use a name only when the correspondence is coherent.

## Canonical functional names
- ZION CORE — internal technological environment / core
- HOLY GHOST — guidance and adaptive learning
- OMAR — Nelson's AI twin / operational intelligence
- SAN PEDRO — keys / registry; locates canonical context and resources
- SAN GABRIEL — messenger / dispatch; carries instructions/events to the proper destination
- BIBLIA — canonical current knowledge
- CRÓNICAS — event/history/correction log
- SERAPHIM — core integrity / alignment; detect corruption of canonical rules, scope and core invariants
- CHERUBIM — security / boundaries; protect access, secrets, PII, production and domain isolation
- THRONES — authority / policy; resolve which authorized rule governs when instructions conflict
- DOMINIONS — governance / delegation
- VIRTUES — capability catalog
- POWERS — runtime enforcement / execution controls
- PRINCIPALITIES — operational domains
- ARCHANGELS — mission coordination
- ANGELS — bounded execution agents

## Adversarial rule
Adversarial actors are never part of ZION CORE's trusted hierarchy. They remain outside ZION as a threat model.

Threat categories may use the following metaphors:
- ADVERSARY — opposition against the system
- DECEPTION — false or manipulative information, prompt injection, fabricated claims or misleading inputs
- INTRUSION — unauthorized access or boundary crossing
- CORRUPTION — poisoning or mutation of trusted knowledge/rules
- LEGION — coordinated or distributed hostile activity

These are threat classifications, not trusted agents and not components that receive authority from ZION.

## Core distinctions
- SERAPHIM asks: Is this faithful to core truth, scope and invariants?
- CHERUBIM asks: Is this actor/action authorized to cross this boundary?
- THRONES asks: Which valid authority or rule governs this decision?
- POWERS enforces runtime restrictions.
- ANGELS perform bounded execution.

SAN PEDRO, SAN GABRIEL, BIBLIA and CRÓNICAS are special functional components, not ranks inserted into the angelic order.
