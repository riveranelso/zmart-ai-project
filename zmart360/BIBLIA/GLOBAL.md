# BIBLIA — Global Rules

## Repetition prevention
Established reusable instructions should be loaded automatically for matching work. Nelson should not have to rebuild recurring prompts from scratch.

## Naming convention
When Zmart 360 needs a new architectural component, prefer a coherent Christian-hierarchy/metaphor name whose meaning matches the technical function. Do not assign names merely to fill a hierarchy.

Current canonical names:
- ZMART 360 — total system
- HOLY GHOST — guidance/adaptive learning
- OMAR — Nelson's central AI twin / operational intelligence
- SAN PEDRO — registry
- SERAFINES — agents
- BIBLIA — canonical knowledge
- ARCANGELES — reserved for genuine multi-agent mission coordination if/when that layer is implemented
- APOSTOLIUM — reserved for a future function that genuinely fits
- EVANGELIUM — reserved for a future distribution/publication function if implemented

SAN PEDRO and SERAFINES are distinct functions and must not be treated as equivalent.
