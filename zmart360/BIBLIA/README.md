# BIBLIA — Zmart 360 Canonical Knowledge

BIBLIA is the canonical durable knowledge store for Zmart 360.

HOLY GHOST decides what deserves to become reusable knowledge. SAN PEDRO records where that knowledge belongs. OMAR retrieves it before execution. SERAFINES consume it while doing work.

## Sections
- `GLOBAL.md` — durable rules that apply across Nelson's work.
- `WORKFLOWS.md` — recurring methods/protocol pointers.
- `BRANDS.md` — brand-specific rules/context pointers.
- `PROJECTS.md` — project/system-specific decisions.
- `ACTIVE_CONTEXT.md` — temporary or campaign-specific state that may change.
- `CHANGELOG.md` — material knowledge changes and supersessions.

## Canonical rule
Do not duplicate the same rule across sections. Store it at the narrowest correct scope and reference it elsewhere.

## Precedence
1. Nelson's explicit current instruction
2. ACTIVE_CONTEXT
3. PROJECTS / BRANDS
4. WORKFLOWS
5. GLOBAL
6. Historical examples

Newer explicit instructions supersede older conflicting entries. Superseded rules must be updated or marked obsolete rather than silently accumulated.

## Privacy
BIBLIA must not contain passwords, API keys, tokens, credentials, customer PII, private lead records or other secrets.
