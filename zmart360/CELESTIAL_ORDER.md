# ZION CORE — Celestial Operating Order

This is a technological metaphor inspired by biblical and Christian terminology. ZION CORE does not represent God. The names describe software responsibilities, not literal spiritual beings.

## Guidance
- HOLY GHOST — guidance and adaptive learning; never subordinate to a created-order metaphor.
- OMAR — Nelson's AI twin / operational intelligence.

## Special functions
- SAN PEDRO — keys / registry.
- SAN GABRIEL — messenger / dispatch.
- BIBLIA — canonical current knowledge.
- BOOK OF REMEMBRANCE — events, corrections and historical learning evidence.

## First order — Core
- SERAPHIM — integrity / alignment.
- CHERUBIM — security / boundaries.
- THRONES — authority / policy.

## Second order — Governance
- DOMINIONS — governance / delegation.
- VIRTUES — capability catalog.
- POWERS — runtime enforcement.

## Third order — Operations
- PRINCIPALITIES — operational domains.
- ARCHANGELS — mission coordinators.
- ANGELS — bounded execution agents.

## Important architectural rule
The orders define responsibility and authority boundaries. They are not required to form a literal synchronous request chain. A task should invoke only the controls and services it needs.

## Human authority
Nelson remains the human authority/operator of the software. OMAR is Nelson's operational representation inside ZION CORE.
