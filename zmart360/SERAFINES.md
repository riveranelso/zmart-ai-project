# SERAFINES — Zmart 360 Agent Layer

SERAFINES are the execution agents of Zmart 360.

They receive bounded missions from OMAR, use the context registered by SAN PEDRO, follow canonical knowledge in BIBLIA, and return evidence/results. They do not invent missing brand rules or silently promote temporary instructions into permanent rules.

## Execution contract
1. Receive a clear mission from OMAR.
2. Resolve the correct context through SAN PEDRO.
3. Load applicable BIBLIA rules and workflow protocols.
4. Execute only within the assigned scope.
5. Return result, evidence, uncertainty and any new correction signal.
6. Never overwrite canonical knowledge on their own; learning signals go through HOLY GHOST.

## Isolation
A SERAFIN may specialize by function or domain, but brand/project context remains isolated.

## Security
Never store or expose secrets, credentials, tokens, customer PII or private lead data.
